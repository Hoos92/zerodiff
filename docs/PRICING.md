# Pricing

Two paid SKUs, one product line. Both grant the same commercial license
to the assurance module (`zerodiff attest` / `zerodiff history`); they
differ in scope of support and engagement, not in which code you may run.

## Free — MIT, forever
Everything a developer needs to verify AI-written changes: record,
replay (isolated/parallel/in-order), reports (json/md/JUnit), quality
gate, scrubbing/redaction, the agent loop (BYO agent or built-in with
your own LLM key), MCP server, GitHub Action, `zerodiff insights`.

## Team — $99/repo/month (early-adopter: $49)
Everything in Free, plus a commercial license for the assurance module in
production: signed tamper-evident attestations (`zerodiff attest`,
code-pinned, git commit recorded), verification history and trends, and
priority email support. For teams shipping AI-assisted changes who need
evidence, not just green checks.

## Enterprise — from $15k/year
Team, plus: verified-migration engagements (we run the pipeline on your
legacy code and deliver the rewrite *with* the attestation), organization
policy ("no merge without attestation"), roadmap priority (HTTP-level
recording for non-Python services, hosted evidence retention, SSO).

## Verified Migration engagements — fixed-bid per module
The full `zerodiff migrate` pipeline run for you on your legacy code:
recorded behavioral baseline, agent-driven rewrite, 100%-of-recorded-
behaviors verification, signed evidence bundle. Priced per migration
scope after a free assessment.
